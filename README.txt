AB-DIGITAL GROWTH — PROFESSIONAL 7-PAGE HTML WEBSITE

PREVIEW
- Extract the ZIP.
- Open index.html in Chrome or another browser.
- Keep the assets folder and styles.css beside the HTML files.

PAGES
Home, Services, Portfolio, Blog, Review, About, Contact.

BEFORE PUBLISHING
1. Buy a domain and choose static web hosting.
2. Replace every occurrence of YOUR-DOMAIN.com in all HTML files and sitemap.xml/robots.txt with your real domain, including https://.
3. Upload all files and the assets folder while preserving the folder structure.
4. Test every page, image, email link, WhatsApp link and form on desktop/mobile.
5. Add your real portfolio items. Placeholders are marked and should be replaced before launch.
6. Add only real client reviews with permission. No fake reviews or results are included.
7. The contact form opens the visitor's email application via mailto. It does not store leads in a database. For reliable submissions, connect a form service or backend.
8. Verify the domain in Google Search Console and submit https://YOUR-DOMAIN.com/sitemap.xml after replacing the placeholder.
9. Add a privacy policy if you add analytics, advertising pixels or collect personal data.
10. SEO-friendly structure cannot guarantee a particular ranking.

GOOGLE SITES
This is a standard HTML website. Google Sites does not import a complete HTML ZIP as a theme. Use a static host for this package, or rebuild the design in Google Sites manually.
